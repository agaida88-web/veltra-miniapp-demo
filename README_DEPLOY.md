# VELTRA — бесплатная демонстрация в Telegram через Render

## Что это

Это **демонстрационная** сборка существующего VELTRA для тестирования интерфейса в Telegram Mini App. Сохранены дизайн, логотип, страницы регистрации/кабинета, графики TradingView и отдельные разделы. В верхней части страницы постоянно показано предупреждение «ДЕМО». Сервер на Python 3.11+ (стандартная библиотека).

**НЕ ИСПОЛЬЗУЙТЕ ЭТОТ БЕСПЛАТНЫЙ ХОСТИНГ ДЛЯ РЕАЛЬНЫХ USDT ИЛИ ЛИЧНЫХ ДАННЫХ.** Приём криптовалюты не настроен, параметры TRON_RECEIVE_ADDRESS и TRON_PAYOUT_ADDRESS намеренно не задаются. В бесплатном Render база SQLite хранится на временном диске и теряется при перезапуске/пробуждении сервиса. Не стоит полагаться на постоянство UID, регистрацию и остатки. Реальные сделки MT4 и вход через Telegram ID не интегрированы; Mini App открывает веб-сайт внутри Telegram.

## Публикация

1. Зарегистрируйтесь на https://github.com/ и на https://dashboard.render.com/.
2. Создайте новый **приватный** репозиторий GitHub, например `veltra-miniapp-demo`. В репозиторий загрузите **содержимое этой папки**, а не ZIP: `render.yaml`, `server.py`, `static/`, `tests/` и `README_DEPLOY.md` должны лежать в корне.
3. В Render выберите **New → Blueprint**, подключите GitHub и свой репозиторий. Render найдёт файл `render.yaml` и создаст веб-службу **Free** с HTTPS автоматически. Следите за статусом **Live**.
4. Откройте полученный адрес `https://<ваше-название>.onrender.com` на смартфоне. После простоя первая загрузка может занимать около минуты.
5. В BotFather выберите бота **@Veltrra_bot → Mini Apps → Main App**, вставьте точный адрес Render в поле **Enter URL**; оставьте **Fullscreen** и нажмите **Save**.
6. Откройте `https://t.me/Veltrra_bot` и нажмите **Open App**.

## Ограничения и безопасность

- Бесплатный веб-сервис Render засыпает после ~15 минут без запросов, запускается на следующем запросе и **не хранит SQLite на постоянном диске**. Для персональных кабинетов нужна отдельная постоянная БД, бэкапы и серьёзный аудит безопасности; бесплатный Render не является продакшен-размещением финансовой системы.
- Не загружайте `.env`, пароли, токены BotFather, TronGrid или приватные ключи в GitHub. Эта сборка не требует токена Telegram-бота.
- Статусы платежей не должны отображаться как успешные, пока не получено реальное подтверждение из блокчейна. Для финансовых функций необходимы KYC/AML и соответствие применимому законодательству.
- На Render не задан администратор. Для тестирования админки можно временно задать `ADMIN_EMAIL` и `ADMIN_PASSWORD` в Render → Environment, но тестовые аккаунты/данные всё равно не сохранятся после перезапуска. Не устанавливайте эти пароли в коде или `render.yaml`.
- Веб-сайт **ещё не имеет Telegram-авторизации** по `initData`; регистрация остаётся через email и пароль. Перед реальным запуском нужно сделать серверную проверку Telegram `initData`, 2FA/защиту входа, надежную БД и независимый аудит.

Документация Render: https://render.com/docs/free , https://render.com/docs/infrastructure-as-code .
Документация Telegram: https://core.telegram.org/bots/webapps .

## Ответ бота на /start (Telegram webhook)

В `server.py` добавлен обработчик Telegram webhook. После изменения GitHub дождитесь нового успешного deploy в Render. В Render → veltra-miniapp-demo → Environment добавьте **секретную** переменную `TELEGRAM_BOT_TOKEN` со значением токена из BotFather. Не добавляйте токен в GitHub, README, чат или скриншоты.

По умолчанию адрес мини-приложения — `https://veltra-miniapp-demo.onrender.com/`, адрес webhook — `https://veltra-miniapp-demo.onrender.com/telegram/webhook`. При смене домена укажите `TELEGRAM_APP_URL` и `TELEGRAM_WEBHOOK_URL` в Render → Environment. Сервер при запуске регистрирует webhook через `setWebhook`; секрет webhook автоматически вычисляется из токена, в код и журналы не выводится. После установки токена проверьте в Render Logs строку `Telegram webhook registered successfully`, затем отправьте в личном чате боту `/start` и нажмите кнопку «🚀 Открыть VELTRA».

Если в логах `Telegram webhook registration failed`, проверьте исходящие запросы Render к Telegram API, токен и URL, не публикуя секрет. На бесплатном тарифе Render сервер может засыпать и отвечать с задержкой. Вебхук не осуществляет платежей и не создаёт аккаунты автоматически.
